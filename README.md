# 🚚 Transport Management System

A Java-based web application that helps transport companies manage vehicle, branch, and user information efficiently.

## 🔧 Technologies Used

- Java, JSP, Servlets
- JDBC, Oracle Database
- HTML, CSS, XML
- Apache Tomcat (optional)
- Git & GitHub

## 👥 User Roles

- **Admin:** Manage managers, view trucks, respond to queries.
- **Manager:** Track trucks, update statuses, view branch performance.
- **Visitor:** View available trucks/services, submit contact queries.

## ✨ Features

- Secure login system for all user roles
- Truck detail management (add/update/search)
- Manager profile & branch performance view
- Emergency truck status update
- Query submission and contact interface for visitors


## ▶️ How to Run

1. Clone the repository
2. Import into Eclipse/IntelliJ as a Dynamic Web Project
3. Configure the Tomcat server
4. Set up Oracle DB schema
5. Run the application
